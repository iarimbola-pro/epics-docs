# Contributing to EPICS

EPICS is distributed in nature, and thus source code and issue trackers
are kept in many different places.
This site combines documentation from more than one of those repositories.
Each project and its maintainers set their own contribution policies.
Follow the guidelines in the repository you intend to change.

## Where to contribute

- [`epics-docs`](https://github.com/epics-docs/epics-docs)
  for general EPICS documentation and the top-level structure of this site.
- [`epics-base`](https://github.com/epics-base/epics-base)
  for EPICS Base source code and version-specific documentation.
- The relevant repository or GitHub organization
  for other EPICS projects.

## Pages published from other repositories

Not every page here comes from `epics-docs`.
Pages under `docs.epics-controls.org/projects/`
are built from their own repositories
and published alongside this one.

Check the address of the page you want to change:
if it contains `/projects/`,
the change belongs in that project's repository.

## If you are unsure where a change belongs

- For problems in the documentation on this site,
  [open an issue in epics-docs](https://github.com/epics-docs/epics-docs/issues).
- For general questions,
  use [Tech-talk](https://epics-controls.org/resources-and-support/mailing-lists/)
  (<tech-talk@aps.anl.gov>)
  or [EPICS Chat](https://epics-controls.org/epics-chat/).

## Pull requests

If you are new to GitHub's contribution flow,
see [Collaborating with pull requests](https://docs.github.com/en/pull-requests/collaborating-with-pull-requests).
